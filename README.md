# StudentOS — Academic Workspace

StudentOS is a modern, vintage inspired academic workspace designed for students to organize tasks, track assignment progress, and run focus sessions.

## Features
* **Assignment Log**: Categorize and track tasks by priority and status.
* **Focus Chronometer**: Built-in Pomodoro timer for study sessions.
* **Milestone Tracking**: Keep track of upcoming exams and project deadlines.
* **Local Persistence**: All data automatically saves to your browser's local storage.
* **Customization**: Dark mode support and interface zoom controls.

## Tech Stack
* **Framework**: React + Vite
* **Styling**: Tailwind CSS
